# Canon 資料庫 README

## Canon 定義

本目錄收錄《星星小說》的 Canon（公認正史）資料。所謂 Canon，指優先級第 1~4 層的內容，也就是：
1. 正文小說章節
2. 使用者明確設定
3. 小說設定文件
4. 多份一致資料

第 5~7 層（推論、構想、AI 想法）**不屬於 Canon**，僅供參考或後續提案使用。

---

## 資料來源

本 Canon 資料庫的一切條目，均來自以下三類來源，優先級由高至低排列：

### 1. 正文（60 章）
- 位置：`novel/chapters/000.md` ~ `novel/chapters/059.md`（共 60 章）
- 性質：**最高權威**，任何其他來源與之衝突時，一律以正文為準

### 2. 設定文件（5 份 DOCX）
- `novel/source/original/小說設定.docx`
- `novel/source/backup/小說備份-第一、二季.docx`
- `novel/source/backup/小說備份-第三、四季.docx`
- `novel/source/backup/尚未登場人物.docx`
- `novel/source/backup/後續安排.docx`

### 3. Penana 最新文字稿
- 位置：`novel/source/penana/downloads/penana-latest.txt`
- 性質：僅作為比對輔助，若與正文或設定文件衝突，以正文 / 設定文件為準

## 7 層優先級（由高至低）

| 層級 | 代號 | 說明 | 是否 Canon |
|------|------|------|------------|
| 1 | 正文 | `novel/chapters/000.md` ~ `059.md` 原文內容 | ✅ 是 |
| 2 | 使用者明確設定 | 使用者在對話中直接給定的指令或設定 | ✅ 是 |
| 3 | 設定文件 | 上述 5 份 DOCX 中的內容 | ✅ 是 |
| 4 | 多份一致資料 | 兩份以上非正文來源一致提到的資訊 | ✅ 是 |
| 5 | [INFERRED] | 由以上資料合理推導而來，但未被原文直接提及 | ❌ 否 |
| 6 | [PROPOSED] | 未確認的構想或提案，尚未獲得作者認可 | ❌ 否 |
| 7 | [AI IDEA] | AI 提出的發想，僅收錄於 `novel/ideas/`，禁止進入 Canon | ❌ 否 |

**重要**：任何進入 Canon 的條目，其來源必須屬於第 1~4 層。第 5~7 層內容**不可**直接寫入 Canon 條目，除非作者後續明確確認。

## 四個標記定義與範例

### [INFERRED] 推論

由第 1~4 層資料合理推導而來，但未被原文直接明說的內容。

**範例**：
```
- [INFERRED] 星星在入學前應有基礎體能訓練，否則無法通過開學第一關。
  Source: Chapter #003（開學第一關通過）、Chapter #005（回憶片段）
```

### [PROPOSED] 未確認構想

尚未獲得作者認可、但具體可行的提案或補丁。

**範例**：
```
- [PROPOSED] 雨之國與風之國之間有一條古老貿易路線，可作為未來支線舞台。
  Source: 小說設定.docx（兩國相鄰）
  狀態：待作者確認
```

### [AI IDEA] AI 發想

AI 單方面提出的想法，僅供作者參考。**禁止寫入 Canon 檔案**，只能存在 `novel/ideas/` 目錄下。

**範例**（僅能出現在 `novel/ideas/ideas.md`）：
```
- [AI IDEA] 星星後續可因某事件短暫接觸到雨之國而展開跨國支線，未經作者確認前僅為構想。
  與 Canon 切割：目前 Canon 僅提到雨之國存在（Source: 小說設定.docx），但尚未涉及跨國旅行內容。
```

### [CONFLICT] 衝突標記

當兩個（含）以上來源對同一議題有不同說法時，必須使用 [CONFLICT] 標記，並包含以下所有欄位：

| 欄位 | 說明 |
|------|------|
| 衝突項目 | 發生矛盾的具體議題 |
| 來源 A 說法 | 第一份資料的說法，附出處 |
| 來源 B 說法 | 第二份資料的說法，附出處 |
| 來源檔案 | 各說法對應的檔案路徑 |
| 章節（若適用） | 正文來源的章節編號 |
| 暫時採用 | 目前暫時採信哪一方（建議以優先級高者為準） |
| 是否待作者確認 | 是 / 否 |

**範例**：
```
- [CONFLICT] 衝突項目：星星的年齡
  來源 A 說法：星星 16 歲
  來源 A：novel/chapters/005.md，Chapter #005
  來源 B 說法：星星 17 歲
  來源 B：novel/source/original/小說設定.docx
  暫時採用：來源 A（正文優先級高於設定文件）
  是否待作者確認：是
```

## Source 格式

所有 Canon 條目均應附上來源，格式如下：

```
Source: Chapter #NNN       ← 引用正文時，NNN 為 0~59 的章節編號
Source: 小說設定.docx       ← 引用設定文件時，直接寫檔名
Source: 小說備份-第一季.docx + 小說備份-第二季.docx   ← 多份來源以 + 連接
```

**範例**：
- 星星為主角。Source: Chapter #001
- 風之國為大陸北方國家。Source: 小說設定.docx
- 開學典禮在第 1 學期第 1 天舉行。Source: Chapter #002 + 小說設定.docx

## 如何更新 Canon

1. **新增條目**：每新增一筆 Canon 條目，**必須附 Source**（屬第 1~4 層來源）。若為 [INFERRED]，應明確標記且仍需附推論依據。
2. **修改既有條目**：若發現新資料與既有條目不同，先判斷優先級：
   - 新資料優先級較高 → 更新條目，並保留舊資訊於註解或討論頁
   - 新資料優先級較低 → 不動 Canon，改以 [PROPOSED] 或 [CONFLICT] 記錄
3. **發現矛盾**：若兩份來源說法不一致，**先標 [CONFLICT]**，再回報作者確認。**禁止**逕自選擇其中一方寫入 Canon 而不標記衝突。

## Canon 安全規則（第 3A 階段）

```text
CANON
= 已由正文或作者確認的正式設定

[INFERRED]
= AI/分析根據正文推導，但不是正式 Canon

[PROPOSED]
= 未經作者確認的未來設定

[AI IDEA]
= AI 自行產生的創作構想

[CONFLICT]
= 不同來源存在無法直接消解的設定差異
```

優先級：

```text
作者明確指示
>
作者確認 Canon
>
正式正文
>
確認設定
>
[INFERRED]
>
[PROPOSED]
>
[AI IDEA]
```

禁止：

```text
[PROPOSED] → 自動變成 CANON
[INFERRED] → 自動變成 CANON
[AI IDEA] → 自動變成 CANON
```

只有作者明確確認後才能升級。所有未確認內容追蹤於 `novel/review/`，
作者確認入口為 `novel/review/author-decisions.md`。
