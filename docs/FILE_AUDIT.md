## 重複資料分析

| 類型 | 判定 | 依據 |
|---|---|---|
| 完全重複 | **無** | 8 檔 SHA-256 皆不同 |
| 部分重複 | **有** | DOCX 備份涵蓋 `#0–#40`；PDF 涵蓋 `#0–#59`。章節標題一一對應，PDF 為超集 |
| 舊版 | `小說備份-第一、二季.docx`、`小說備份-第三、四季.docx` | mtime 2026-06-21；PDF mtime 2026-07-15；DOCX 止於 #40，PDF 多出 #41–#59 |
| 最新版（正文） | `說好一起當吊車尾-妳神化全開yJS9juj4220.pdf` | 章節範圍最大（#0–#59），時間較新 |
| 最新版（規劃） | `後續安排.docx` | mtime 2026-09-23；涵蓋 #60–#70 大綱，超出所有正文來源 |
| 無法確認 | DOCX 與 PDF 同章節的逐字差異程度 | PDF 使用相容漢字區塊，逐行比對重疊為 0；**不能**在未歸一化比對前宣稱逐字相同或不同 |

處理原則（依規則）：

- 不刪除任何檔案。
- DOCX 備份雖可能為舊版，但保留於 `novel/source/backup/`，**不**移入 `archive/`（無完全重複證據）。
- 正文以 PDF 為主來源；DOCX 備份保留作離線保險。
